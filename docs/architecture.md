# Архитектура

Статичный сайт Burger VPN: лендинг `index.html`. Без сборки и серверной части — HTML, CSS
и JS лежат в репозитории как есть и открываются любым статическим сервером. Выкладка —
GitHub Pages из ветки `main`.

## Как поднять, проверить и выложить

- Локально: в корне `python -m http.server 5173 --bind 127.0.0.1`, затем
  http://127.0.0.1:5173/. Файлом через `file://` страница тоже откроется, но предзагрузка
  шрифтов упадёт с ошибкой CORS в консоли — для работы удобнее сервер.
- Автотестов нет. Проверка — глазами на ширинах 340, 480, 768, 1024, 1240, 1440 и с
  включённым «уменьшением движения» в системе: у каждой анимации есть спокойный вариант.
- Выкладка: `git push` в `main`, Pages собирает сайт из корня ветки за минуту-две.

## Правила, которые нельзя нарушать

- **БЭМ и файлы.** Блок — это файл в `css/blocks/` и, если есть поведение, файл с тем же
  именем в `js/blocks/`. Состояния — модификаторами (`faq__item_open`, `header_hidden`).
  Держится на договорённости, линтера нет.
- **JS не опирается на оформление.** Корень блока и точки управления ищутся по
  `data-*`; классы меняются только ради стилей.
- **Единица макета `--u`.** `calc(100cqi / 440)` — один пиксель макета шириной 440,
  считается от ближайшего контейнера: на телефоне это `.page`, с 768px — каждая
  `.page__tile`. Размеры задаются как `clamp(минимум, N * var(--u), максимум)`, чтобы
  на телефоне совпадать с макетом, а на ПК не разрастаться. Новому контейнеру
  (`container-type`) внутри плитки нужно помнить, что `--u` внутри него пересчитается.
- **Сетка.** До 768px секции идут встык, как в макете. С 768px — плитки в одну колонку,
  с 1024px — бенто на 12 колонок через `grid-template-areas` в `base.css`. Новая секция
  получает `page__tile page__tile_area_<имя>` и строку в шаблоне сетки.
- **Движение.** Анимируются `transform`, `opacity`, отдельные `translate`/`scale`/`rotate`.
  Под `prefers-reduced-motion: reduce` у каждого блока свой спокойный вариант.
- **Без скриптов страница читается.** Скрытые до анимации состояния пишутся под `.js`,
  без него контент виден сразу.
- **Связь блоков — событиями:** `tabs:change` на элементе вкладок, `payment:open` и
  `modal:open`/`modal:close`. Прямых вызовов чужих функций нет, кроме `Burger.modal`.

## Точки входа и адреса

- `/` — лендинг.
- `/index.html#activation` — лендинг сразу с открытым окном подключения.
- Внешних запросов нет: шрифты, слайдер и картинки свои. Ссылки на бота
  `https://t.me/VpnBurger_bot` и юридические документы (`#`) — заглушки до настоящих адресов.
- Формы никуда не отправляются: окна подключения и оплаты показывают интерфейс из макета.

## Внешние зависимости и что будет без них

- **Keen Slider** лежит в `js/vendor/`. Если скрипт не загрузился, `tariffs.js` выходит
  сразу: четыре бургера стоят в ряд, тариф, период и число устройств не переключаются.
- **Шрифт Asgard Wide — пробная версия** (некоммерческая лицензия, цифры в ней
  заменены штампом TRIAL, поэтому цифры берутся из Unbounded). Перед публичным запуском
  нужна купленная версия; тогда грани Unbounded в `fonts.css` можно убрать.
- **GitHub Pages.** Сайт статичный, поэтому переезжает на любой хостинг копированием файлов.
